# Генератор шрифтов Firefight

[中文](README.md) · [English](README.en.md) · [Русский](README.ru.md)

Превращает любой шрифт `.ttf` / `.otf` в **PNG-атлас, который Firefight читает напрямую**, — им можно заменить шрифт в игре.

Веб-версия — один файл `index.html`: ничего не устанавливается, внешних зависимостей нет, достаточно открыть файл или положить его на любой статический сервер.

## Загрузка и установка (APK для Android)

Если не хочется открывать браузер: скачайте последний `Firefight-Font-Generator-*.apk` на странице [Releases](https://github.com/i-HatobaTsugu-i/Firefight-Fonts-Generator-Web/releases) и установите.

- APK — это оболочка WebView с той же страницей `index.html`; интерфейс, функции, три языка и автосохранение работают так же, как в веб-версии.
- Android предупредит о «неизвестном источнике» — разрешите установку.
- APK подписан постоянным ключом из репозитория (`android/signing/keystore.p12`), поэтому **новые версии ставятся поверх старых**. Если установлена ранняя debug-сборка, её нужно один раз удалить.
- Ключ и пароль лежат в репозитории открыто (любой может подписать обновление, которое система сочтёт тем же приложением). Если это важно — замените ключ своим или передавайте его через Secrets репозитория.
- При запуске приложение сравнивает версию с последним релизом и предлагает обновиться (пункт «Позже» запоминает эту версию и больше не мешает).

> Версия имеет вид «дата.номер-изменения-за-день», например `2026.10.28.4`. Она хранится в `APP_VERSION` внутри `index.html` и показывается в подвале страницы. Каждый push в `main` запускает GitHub Actions: APK собирается и публикуется релизом с тем же тегом (правки одного README сборку не запускают).

> К каждому релизу автоматически прилагается список изменений, собранный из истории коммитов.

## Разрешения и каталоги

APK запрашивает ровно одно разрешение и работает только со следующими местами:

| Разрешение | Назначение |
| --- | --- |
| `INTERNET` | Только для запроса `releases/latest` на GitHub при проверке обновлений. Данные никуда не отправляются, сама страница работает офлайн. |

| Каталог | Назначение |
| --- | --- |
| Системная папка **Download** | Куда сохраняются экспортированные PNG / zip; на Android 10+ запись идёт через MediaStore |
| `Android/data/<пакет>/files/Download` | Запасное место на Android 8 / 9, где нет системной коллекции загрузок |
| Выбранный вами файл шрифта | Читается один раз через системный выбор файлов (SAF), только тот файл, который вы указали |
| Приватный каталог приложения (данные WebView) | Настройки (localStorage) и копия шрифта (IndexedDB); удаляются вместе с приложением |

Разрешение на доступ к хранилищу не запрашивается, фото, контакты и другие папки не читаются, аналитики и рекламных SDK нет. Ссылки из подвала открываются в системном браузере.

## Возможности

- **Генерация атласа**: сетка 16 × 16, ячейка 64px в раскладке 1024; экспорт в 512 (ячейки 32px) или 1024 (ячейки 64px), можно оба размера сразу.
- **Две версии раскладки**
  - Новая: как в оригинальном атласе, порядок байтов от `U+0020` до `U+00FE`, диапазон `0x80–0x9F` берётся из Windows-1252, неопределённые позиции остаются пустыми.
  - Старая: ASCII, затем 34 пробела, затем Latin-1 (`¡`–`þ`).
- **Правка отдельного символа**: нажмите на ячейку, затем меняйте ширину / высоту (по контуру глифа, ±px) и сдвиг по горизонтали / вертикали (±px). Числовые поля и ползунки синхронизированы, обрезку по ячейке можно выключить.
- **Насыщенность**: переключатель обычный / жирный, а при экспорте можно отметить «экспортировать обычный + жирный».
- **Цвета**: фон страницы следует за цветом текста (тёмный или светлый), чтобы глиф всегда был виден; экспортированные изображения **всегда с прозрачным фоном**.
- **Кегль**: ползунок и поле ввода, принимает px (например `48`) или множитель (например `1.5` или `1.5x`).
- **Встроенное руководство**: кнопка с книгой рядом с заголовком открывает описание всех элементов, у каждого показан макет реального контрола.
- **Собственные контролы и анимации**: выпадающий список раскладки, «пилюля» насыщенности, чекбоксы, меню языков и панель цвета сделаны вручную, с анимациями открытия / закрытия / выбора; в палитре есть готовые цвета, ползунок тона, поле насыщенности-яркости и связанные поля RGB / HSV / CMYK.
- **Экспорт без шрифта**: если шрифт не загружен, рендерится системный шрифт устройства (об этом сообщает диалог экспорта).
- **Сброс шрифта**: кнопка «Убрать шрифт» рядом с именем файла выгружает шрифт, удаляет его копию и сразу возвращается к системному.
- **Автосохранение**: шрифт, кегль, цвет, раскладка, насыщенность и все деформации символов хранятся в браузере и восстанавливаются при следующем открытии.
- **Экран при запуске**: при каждом открытии сначала показывается окно с копирайтом и отказом от ответственности; его текст берётся из соответствующего раздела этого README (офлайн — встроенный текст).
- **Проверка обновлений**: после запуска запрашивается последний релиз, и при наличии новой версии появляется предложение обновиться.
- **Три языка**: 中文 / English / Русский, переключение круглой кнопкой в правом верхнем углу.

## Как пользоваться

1. Откройте `index.html` (двойной щелчок локально либо разместите на GitHub Pages / любом статическом сервере).
2. Нажмите «Загрузить шрифт» и выберите `.ttf` / `.otf` (можно не загружать и экспортировать системным шрифтом). Рядом с именем файла появится кнопка «Убрать шрифт».
3. Настройте кегль, насыщенность и цвет; нажмите на ячейку в атласе, чтобы выбрать символ и подправить его ползунками.
4. Нажмите «Скачать PNG» и выберите 512 / 1024 / оба:
   - один файл скачивается напрямую как PNG, например `font_image_512.png`;
   - несколько файлов упаковываются в один `font_image.zip` (иначе браузер блокирует вторую автоматическую загрузку).
5. Замените файлы шрифта в игре на экспортированный PNG согласно требованиям вашего мода.

## Структура атласа

| Параметр | Версия 512 | Версия 1024 |
| --- | --- | --- |
| Холст | 512 × 512 | 1024 × 1024 |
| Ячейка | 32 × 32 | 64 × 64 |
| Сетка | 16 столбцов × 16 строк | 16 столбцов × 16 строк |
| Занято | первые 14 строк (223 позиции) | первые 14 строк (223 позиции) |

- Соответствие индекса и байта: `индекс = значение байта − 0x20`, поэтому первая ячейка — пробел `0x20`, а ячейка 224 соответствует `0xFF` (в оригинальном атласе она пустая, здесь тоже).
- Пять позиций, где в оригинале нет глифов (`€`, `…`, `Ž`, `•`, `ž`), остаются пустыми.
- Фон полностью прозрачный: пиксели есть только у самих глифов, поэтому атлас сразу ложится в игру.

## Ограничения

- **Жирность синтетическая**: при загрузке одного файла браузер имитирует жирное начертание, оно отличается от настоящего Bold. Для точного вида загрузите файл с Bold.
- **Подстановка отсутствующих глифов**: символы, которых нет в вашем шрифте, рисует системный шрифт — позиция верная, начертание чужое. Если шрифт не загружен вообще, весь атлас будет системным.
- **Хранение**: настройки в `localStorage`, копия шрифта в `IndexedDB`. При открытии через `file://` часть браузеров блокирует `IndexedDB`, и автосохранение перестаёт работать; через http (локальный сервер или GitHub Pages) всё в порядке.
- **Старые движки**: в некоторых старых мобильных WebView событие `close` у `<dialog>` не возникает, поэтому экспорт запускается прямо из кнопок выбора.

## Сборка APK из исходников

```bash
cp index.html android/app/src/main/assets/index.html   # положить страницу в assets
cd android && gradle assembleRelease                   # результат: app/build/outputs/apk/release/app-release.apk
```

Нужны JDK 17, Android SDK 34 и `android/signing/keystore.p12` (без него release-сборка останется неподписанной). CI делает всё это сам; локально обычно достаточно веб-версии.
