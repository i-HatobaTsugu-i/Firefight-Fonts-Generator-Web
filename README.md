# Firefight 字体图片生成器

[中文](README.md) · [English](README.en.md) · [Русский](README.ru.md)

把任意 `.ttf` / `.otf` 字体转成 **Firefight 能直接读取的字体 PNG 图集**，用来替换游戏内的字体。

网页版就是一个 `index.html`：无需安装、不依赖外部资源，双击或放到任意静态服务器即可使用。

> Firefight Font Atlas Generator — turn any TTF/OTF into the font PNG atlas that Firefight reads, so you can replace the in-game typeface. Single-file page, offline, no build step.

## 下载 / 安装（Android APK）

不想开浏览器也能用：到 [Releases](https://github.com/i-HatobaTsugu-i/Firefight-Fonts-Generator-Web/releases) 下载最新的 `Firefight-Font-Generator-*.apk` 安装即可。

- APK 是一个 WebView 壳，内置同一份 `index.html`，界面、功能、三语、自动保存都与网页版一致；
- 安装时会提示「未知来源应用」，允许后安装；
- APK 使用仓库内固定密钥（`android/signing/keystore.p12`）签名，**后续版本可直接覆盖安装**；但从早期 debug 签名的版本升级时，需要先卸载一次旧版；
- 启动时会自动比对仓库最新版本，发现新版会弹窗询问是否更新（选「以后再说」会记住该版本，不再重复提示）。

> 版本号统一为「日期.当天第几次修改」，例如 `2026.10.28.4`，写在 `index.html` 的 `APP_VERSION` 里，页面页脚也会显示。每次把改动推到 `main`，GitHub Actions 都会读取它编译 APK，并以同名 tag 发布到 Release（只改 README 不触发构建）。

> 每次发布的 Release 都会附带按提交记录自动汇总的更新日志，见 Release 页面正文。

## 权限与目录

APK 只申请一项权限，并且只读写下面这些位置：

| 权限 | 用途 |
| --- | --- |
| `INTERNET` | 仅用于请求 GitHub 的 `releases/latest` 接口检查更新，不上传任何数据；页面本体完全离线 |

| 目录 / 位置 | 用途 |
| --- | --- |
| 系统「下载」（Download） | 导出 PNG / zip 的默认保存位置，Android 10 及以上通过 MediaStore 写入 |
| `Android/data/<包名>/files/Download` | Android 8 / 9 没有系统下载集合时的退回位置 |
| 你手动选择的字体文件 | 通过系统文件选择器（SAF）临时读取，只读你选中的这一个文件 |
| 应用私有目录（WebView 数据） | 保存设置（localStorage）和字体副本（IndexedDB），卸载即清除 |

不申请存储权限，不读取相册、通讯录等其他目录，也不含任何统计或广告 SDK；点击页脚链接时交给系统浏览器打开。

## 功能

- **图集生成**：16 列 × 16 行、每格 64px 的 1024 图集结构，按 512（32px 格子）或 1024（64px 格子）导出，也能两个尺寸一起出。
- **排版版本可切**
  - 新版：与原版字体图一致，从 `U+0020` 按字节顺序排到 `U+00FE`，其中 `0x80–0x9F` 取 Windows-1252 字形，编码未定义的位置留空。
  - 旧版：ASCII 之后补 34 个空格，再接 Latin-1（`¡`–`þ`）。
- **单字微调**：点画布上任意一格选中字符，可拉宽 / 拉高（按字形墨迹 ±px）、水平 / 垂直位移（±px），数字框与滑块双向同步，可选「裁剪到格内」。
- **字重**：常规 / 加粗一键切换，导出时能勾选「同时导出常规 + 加粗」。
- **配色**：页面背景自动跟随字色取深 / 浅主题，挑字时看得清；导出的图片**始终是透明底**，背景色不会进入图片。
- **字号**：滑块 + 输入框，可直接填 px（如 `48`），也可填放大倍率（如 `1.5` 或 `1.5x`）。
- **内置用户手册**：标题右侧带「用户手册」字样的书本按钮，点开逐项说明每个控件，每一项都内嵌主界面控件的示意，方便对照。
- **自绘控件与动效**：排版下拉、字重滑片、勾选框、语言菜单、取色面板均为自绘，带展开 / 收起 / 选中动画；字色使用自建取色器（推荐颜色、色相滑杆 + 明度饱和度区、RGB / HSV / CMYK 互相联动）。
- **免字体导出**：不载入任何字体也能直接导出，此时用设备系统字体渲染（导出弹窗会提示）。
- **一键清除字体**：点字体名旁的「清除字体」即可卸载当前字体并删掉浏览器里的副本，立即回落到系统字体。
- **自动保存**：字体文件、字号、字色、排版、字重、每个字的变形都保存在浏览器里，刷新或下次打开自动恢复。
- **启动声明**：每次打开先弹出版权与免责声明，内容实时读取本文件对应语言的章节（离线时用内置文案）。
- **自动检查更新**：启动后对比仓库最新 Release，有新版本会弹窗询问是否前往下载。
- **三语界面**：中文 / English / Русский，右上角圆形按钮切换。

## 使用

1. 打开 `index.html`（本地双击，或放到 GitHub Pages / 任意静态服务器）。
2. 点「载入字体」选择你的 `.ttf` / `.otf`（不载入也可以，直接用系统字体导出）。载入后字体名旁会出现「清除字体」，点一下即可卸载。
3. 调整字号、字重、字色；点画布上的格子选中某个字，用滑块做单字微调。
4. 点「下载 PNG」，选择 512 / 1024 / 两者：
   - 只有一个文件时直接下载 PNG，例如 `font_image_512.png`；
   - 需要多个文件时打包成一个 `font_image.zip`，一次下载完（避免浏览器拦截连续下载）。
5. 按你的 mod 要求，把导出的 PNG 替换到游戏字体目录。

## 图集结构

| 项目 | 512 版 | 1024 版 |
| --- | --- | --- |
| 画布尺寸 | 512 × 512 | 1024 × 1024 |
| 每格尺寸 | 32 × 32 | 64 × 64 |
| 行列 | 16 列 × 16 行 | 16 列 × 16 行 |
| 实际使用 | 前 14 行（223 个字符位） | 前 14 行（223 个字符位） |

- 索引与字节值的关系：`索引 = 字节值 − 0x20`，所以第 1 格是空格 `0x20`，第 224 格对应 `0xFF`（原版图集这一格是空的，本工具也不排字）。
- 原版字体图里缺字形的 5 格（`€`、`…`、`Ž`、`•`、`ž` 对应位置）按原图保持空白。
- 背景完全透明，只有字形本身有像素，直接叠进游戏不会带底色。

## 已知限制

- **加粗是合成粗体**：只加载一个字体文件时，浏览器会合成加粗，和字体自带的 Bold 字重不会完全一样。想要真粗体，请直接载入 Bold 字重的文件。
- **缺字回退**：字体里没有的字形会由系统字体补画，位置对但字形不是你的字体；完全不载入字体时，整张图集都是系统字体。
- **存储位置**：设置存在 `localStorage`，字体文件存在 `IndexedDB`。用 `file://` 直接打开时，部分浏览器会禁用 `IndexedDB`，自动恢复会失效；换成 http（本地服务器或 GitHub Pages）即正常。
- **旧内核兼容**：移动端个别旧内核的 `<dialog>` 不派发 `close` 事件，代码里已改成在选项按钮上直接执行。

## 从源码构建 APK

```bash
cp index.html android/app/src/main/assets/index.html   # 先把页面放进 assets
cd android && gradle assembleRelease                   # 产物：app/build/outputs/apk/release/app-release.apk
```

需要 JDK 17 + Android SDK 34，以及 `android/signing/keystore.p12`（没有则打不出已签名的 release 包）。CI 会自动完成这些步骤，本地一般只跑网页版验证。
